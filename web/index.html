Stop paying for sandboxes. Run coding agents on your own VM.

forgerun is an open-source, self-hosted AI coding agent runner that executes Claude Code, Cursor CLI, OpenCode, and Pi on your GitHub repositories. Every conversation thread runs in its own isolated sandbox — a hardware-virtualized microVM via microsandbox (libkrun) on Apple Silicon Macs and Linux with KVM, or a gVisor user-space kernel sandbox on any standard Linux VPS without nested virtualization.

Try it yourself with one command: curl -fsSL https://raw.githubusercontent.com/depak7/forgerun/main/install.sh | sh

How it works

  1. 01. Give it a task

    Pick a GitHub repository, an agent (cursor, claude-code, opencode, or pi), and a model, then describe what you want changed — or ask for a read-only plan first and approve it before any code is modified.

  2. 02. It works in an isolated microVM

    The agent clones your repository, installs packages, builds, and runs tests inside its own dedicated VM. Warm disk snapshots reduce task startup time from 26.8 seconds to 2.8 seconds (measured on expressjs/express with 304 npm packages pre-installed). The VM stays alive between follow-up messages so the agent retains its working tree and conversation context.

  3. 03. Review the diff, then push

    Inspect the live execution log and unified git diff for each turn in the web UI. When satisfied, press push to publish a single squashed commit to a forgerun/… branch and optionally open a GitHub pull request.

Why it's safe to point at your code

  • One sandbox per thread

    Each thread executes inside its own libkrun microVM (or a gVisor runsc container with a dedicated user-space kernel burning 0.34s cold boot on KVM-less Linux hosts). Untrusted code and dependencies stay isolated from your host kernel.

  • Keys never enter the sandbox

    Inside the sandbox, credential environment variables contain only inert placeholders ($MSB_… or FORGERUN_PH_…). A host-side TLS proxy swaps in the real API key exclusively for requests destined to the agent's official API endpoint.

  • Nothing reaches GitHub until you push

    Agents have no GitHub push credentials inside the sandbox. Changes are extracted as a git patch and only pushed by the host when you explicitly click push.

Supported Agents & Subscriptions

  • cursor — Cursor CLI with full model catalog, thinking modes, and effort controls.
  • claude-code — Anthropic Claude Code (Sonnet, Opus, Fable) using your existing Claude Pro or Max subscription via claude setup-token.
  • opencode — OpenCode CLI, including zero-configuration free models that require no API key.
  • pi — Multi-provider coding agent supporting OpenRouter, OpenAI, and Anthropic keys.

Run it yourself

Deploy everything in one binary (forgerun serve) on an Apple Silicon Mac or Linux server, or split the lightweight web orchestrator (forgerun server) on a $5 VPS while connecting outbound workers (forgerun worker) from your own hardware over HTTPS with zero open inbound ports. Run forgerun doctor anytime to verify KVM, gVisor, microsandbox, Postgres, and token readiness.
